# ZosyaHandmadePictures

Сайт-галерея текстильных картин: https://zosyahandmade.ru

Статический сайт с админкой. Работы, цены, фото и контакты редактируются в админке (`/admin/`), после сохранения сайт пересобирается сам.

## Запуск на компьютере

Нужен Node.js 20+.

```
npm install     # один раз
npm run dev     # сайт: http://localhost:5173, админка: http://localhost:5173/admin/
```

Локальная админка сохраняет изменения прямо в папку проекта и сразу пересобирает сайт. Вход для неё не нужен.

## Где что лежит

| Путь | Что внутри |
|---|---|
| `content/artworks.json` | Работы (редактируются в админке) |
| `content/settings.json` | Курс доллара, контакты, фото главной (редактируются в админке) |
| `images/uploads/` | Исходные фото, которые загрузили через админку |
| `data/i18n.mjs` | Все тексты сайта на русском и английском |
| `site.config.mjs` | Адрес сайта, репозиторий GitHub, категории |
| `assets/favicon.svg` | Иконка сайта (PNG и ICO собираются из неё сами) |
| `src/` | Оформление и скрипт сайта |
| `admin/` | Админка |
| `lib/build.mjs` | Сборка: главная, страница каждой картины, 404, sitemap |
| `lib/images.mjs` | Сжатие фото: WebP нескольких размеров + JPEG для Pinterest |

## Как устроена публикация

1. Код и данные лежат в репозитории на GitHub.
2. Админка на сайте (`zosyahandmade.ru/admin/`) сохраняет изменения прямо в репозиторий.
3. GitHub Actions (`.github/workflows/deploy.yml`) собирает сайт и выкладывает его на GitHub Pages. Это занимает 1–2 минуты, админка показывает, когда изменения уже на сайте.

### Первичная настройка (один раз)

1. Репозиторий: https://github.com/MrRadrigos/zosyahandmade (публичный — так GitHub Pages бесплатен).
2. В `site.config.mjs` указан `GITHUB_REPO = 'MrRadrigos/zosyahandmade'`.
3. В репозитории: Settings → Pages → Source: **GitHub Actions**; Custom domain: `zosyahandmade.ru`, включить Enforce HTTPS.
4. У регистратора домена в DNS прописать:
   - четыре записи `A` для `@`: `185.199.108.153`, `185.199.109.153`, `185.199.110.153`, `185.199.111.153`;
   - запись `CNAME` для `www`: `mrradrigos.github.io`.
5. Войти в админку: она сама объяснит, как создать ключ доступа.

### Второй домен (например, .art)

У сайта один основной адрес. Остальные домены настраиваются на переадресацию (301) на него: у регистратора это обычно называется «переадресация домена». Тогда старые ссылки и пины работают с любого адреса.

## Работы и фото

- Порядок работ в админке совпадает с порядком на сайте.
- Первое фото работы главное: оно в каталоге и в превью для Pinterest.
- Админка уменьшает фото перед загрузкой, сборка делает из них WebP 480–1800px и JPEG 1200px для соцсетей.
- Адрес страницы работы (`/art/<адрес>/`) задаётся при создании и потом не меняется, чтобы пины не ломались.
- Проданную работу лучше отметить «Продано», а не удалять: ссылки на неё продолжат работать.

## Цены в долларах

На английской версии цены показываются в долларах. Если у работы не указана своя цена в $, она считается по курсу из настроек и округляется до $5–10.
